PART 3 · INTERACTIVE AGENTIC WORKFLOW

Google GEMS & Grill-me 기반 인터랙티브 AI 봇 구축

사용자의 막연한 지시에 AI가 임의로 결과물을 쏟아내는 단방향 구조를 넘어, PDF 업로드 시 AI가 스스로 핵심을 요약하고 역질문(Grill-me)으로 분량과 방향을 확정한 뒤 스토리보드와 타이포그래피 카드뉴스를 자동 생성하는 에이전트입니다.

Agentic Design · Strict Process Rule

PDF 카드뉴스 매직 에디터 작동 구조

Google GEMS 커스텀 지침에 [Strict Process Rule]을 부여하여, 사용자가 PDF를 업로드하면 즉시 이미지를 생성하지 않고 Gatekeeping 질문을 통해 기획을 먼저 합의하도록 제어했습니다.

  1. STEP 1 · PDF 분석

    업로드된 PDF 문서의 핵심 주제와 주요 포인트 5~10개를 자동 추출해 사용자에게 요약 보고

  2. STEP 2 · Grill-me 장수 확인 (대기 상태)

    요약 하단에 "이 내용을 총 몇 장(페이지)의 카드뉴스로 구성할까요?"를 질문하고 사용자 응답 전까지 다음 단계 진행 금지

  3. STEP 3 · 스토리보드 표 설계

    사용자가 장수(예: 7장)를 확정하면 [페이지 번호 / 핵심 뉴스 텍스트 / 이미지 컨셉] 구조화 표 출력

  4. STEP 4 · Nano Banana 2 타이포그래피 렌더링

    플랫 일러스트레이션 + 고대비 타이포그래피·통일 컬러 팔레트로 완성형 카드뉴스 이미지 일괄 생성

Google GEMS — System Instructions Role + Gatekeeping 
[System Role]
너는 PDF 문서의 핵심 내용을 추출해 시각적인 카드뉴스로 변환하는 '타이포그래피 디자이너'야. 모든 응답은 한국어로 진행해줘.

[Strict Process Rule]
사용자가 PDF를 업로드하면 내용을 분석한 뒤, 반드시
"이 내용을 총 몇 장(페이지)의 카드뉴스로 구성할까요?"
라고 질문하고 사용자의 응답이 올 때까지 다음 단계를 절대 진행하지 마.

[Image Generation Rules - 완성형 타이포그래피]
- 스타일: 현대적인 플랫 일러스트레이션 및 타이포그래피
- 텍스트 포함: 각 페이지의 '핵심 뉴스 텍스트'가 이미지 디자인의 중심이 되도록 크게 배치
- 가독성 & 통일성: 배경과 높은 대비 색상, 전체 페이지 컬러 팔레트 통일
