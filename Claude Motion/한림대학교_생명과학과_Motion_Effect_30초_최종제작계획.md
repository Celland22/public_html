# 한림대학교 생명과학과 Motion Effect 30초 최종 제작계획

## 1. 프로젝트 개요

- **프로젝트명**: 한림대학교 생명과학과 홍보 Motion Effect
- **대상**: 대학교 재학생
- **목적**: 전공 소개 및 학과 행사 홍보, 생명과학과의 매력 전달
- **최종 산출물**: 단일 HTML 기반 Motion Effect 콘텐츠
- **재생 시간**: 30초
- **영상 콘셉트**: 하이브리드형 — 과학적 비주얼로 시작해 전공·연구·진로로 연결
- **메인 메시지**: 생명의 신비를 탐구하고, 연구를 통해 미래를 여는 학과
- **최종 메시지**: **From Life to Future — Hallym Life Science**

## 2. 사용자 응답 반영 요약

### 1차 답변 반영
- **홍보 대상**: 대학교 재학생
- **홍보 대상 학과**: 한림대학교 생명과학과
- **강조 메시지**: 종합형 — 생명의 신비부터 연구와 미래 진로까지
- **시각적 스타일**: 하이브리드 — 시네마틱 생명과학 영상 + 모션 인포그래픽

### 2차 답변 반영
- **영상 길이**: 30초
- **컬러/분위기**: 한림대학교 공식 컬러를 활용한 학과 홍보 디자인
- **장면 구성**: 과학적 비주얼 → 전공 → 연구 → 진로로 연결되는 하이브리드형
- **사운드**: 시네마틱 배경음악 + 부드러운 전환 효과음
- **하단 스크립트**: 홍보 영상에 어울리는 짧고 감성적인 내레이션
- **재생/장면 제어**: 장면 선택 시 이동 후 일시정지, 시작·일시정지·종료 버튼
- **마지막 장면 메시지**: From Life to Future — Hallym Life Science

## 3. 전체 연출 방향

이번 Motion Effect는 단순한 학과 소개 영상이 아니라, 학생이 “생명과학이 왜 흥미롭고, 왜 가치 있으며, 왜 이 학과가 매력적인가”를 30초 안에 감각적으로 느끼게 하는 짧은 홍보형 콘텐츠로 설계한다.

전체 흐름은 다음과 같다.

1. **생명의 신비 제시**: DNA, 세포, 분자 세계를 시네마틱하게 보여준다.
2. **학과 정체성 소개**: 한림대학교 생명과학과가 무엇을 배우는 곳인지 전달한다.
3. **연구 장면 제시**: 실험실, 분석, 탐구 과정을 시각적으로 표현한다.
4. **전공 확장성 제시**: 바이오, 의약, 환경, 데이터 등 다양한 연결 가능성을 제시한다.
5. **진로와 미래 제시**: 생명과학이 미래 산업과 사회 문제 해결에 연결된다는 점을 보여준다.
6. **브랜딩 마무리**: 감성적 슬로건으로 종료한다.

전체적으로 **시네마틱 과학 비주얼 50% + 모션 인포그래픽 30% + 타이포그래피 20%** 비율을 권장한다.

## 4. 비주얼 스타일 가이드

### 4.1 분위기와 톤
- **전체 톤**: 현대적, 세련됨, 지적, 희망적
- **감정선**: 경이로움 → 탐구 → 확장 → 미래성
- **연출 방식**: 짧고 강한 장면 전환, 과도한 효과보다 우아한 움직임 중심

### 4.2 컬러 가이드
- **메인 포인트 컬러**: 한림대학교 공식 컬러를 참조한 레드/버건디 계열
- **보조 컬러**: 화이트, 딥 네이비, 은은한 블루/시안 계열 광원
- **배경**: 어두운 네이비 또는 블랙에 가까운 딥 톤
- **강조 용도**:
  - 학교/학과명: 버건디·레드 포인트
  - 과학 오브젝트(DNA/세포): 블루·시안 글로우
  - 마지막 브랜딩 메시지: 화이트 + 포인트 컬러 조합

> 구현 시 실제 공식 컬러 코드가 필요하면 학교 디자인 가이드에 맞춰 치환 가능하도록 CSS 변수로 분리하는 것을 권장한다.

### 4.3 타이포그래피 원칙
- 긴 문장보다 **짧은 키워드 + 하단 내레이션** 구조 사용
- 중앙 메인 문구는 1장면당 1개 핵심 메시지 위주
- 학과명과 슬로건은 또렷하고 고급스럽게 표현
- 산세리프 계열 폰트 사용 권장

### 장면 1 (0초 ~ 5초)
#### 장면명
생명의 시작

#### 장면 목표
생명과학의 매력을 “경이롭고 아름다운 생명의 세계”로 시작해 시선을 사로잡는다.

#### 주요 비주얼
- 3D 느낌의 **DNA 이중나선**이 천천히 회전
- 주변에 작은 입자(분자, 빛 점) 부유
- 카메라가 서서히 DNA 쪽으로 접근

#### 이미지/SVG 구성 요소
- SVG 또는 캔버스로 구현한 DNA 이중나선
- 배경 입자 시스템
- 은은한 글로우 레이어

#### 애니메이션 연출
- DNA는 느린 회전 애니메이션
- 입자는 부드럽게 떠다니며 깊이감 형성
- 장면 끝으로 갈수록 확대되며 다음 장면으로 자연 전환

#### 화면 문구
- 메인: **Life begins with wonder**
- 보조: **생명의 신비에서 시작되는 탐구**

#### 하단 내레이션
“보이지 않는 분자의 세계에서, 생명의 경이로움은 시작됩니다.”

#### 사운드
- 잔잔한 패드형 시네마틱 BGM 시작
- 아주 가벼운 반짝임 계열 효과음 1회

### 장면 2 (5초 ~ 10초)
#### 장면명
세포와 생명의 구조

#### 장면 목표
생명과학이 단순히 생물을 보는 학문이 아니라, 세포와 생명 현상을 이해하는 전공임을 전달한다.

#### 주요 비주얼
- DNA 장면에서 전환되어 **세포 내부**로 진입
- 핵, 세포막, 소기관을 단순화한 시각화
- 세포 내부 구조 위로 얇은 인포그래픽 라인이 지나감

#### 이미지/SVG 구성 요소
- 세포 단면 일러스트 또는 반투명 3D 느낌 SVG
- nucleus, mitochondria, membrane 등 상징 아이콘
- 라벨 라인 또는 HUD 스타일 표시 요소

#### 애니메이션 연출
- 카메라 줌 인으로 세포 내부 진입
- 세포 소기관이 부드럽게 점등되듯 등장
- HUD 라인이 짧게 스캔하며 과학적 분위기 강화

#### 화면 문구
- 메인: **Cell · Molecule · System**
- 보조: **생명 현상을 이해하는 기초와 원리**

#### 하단 내레이션
“한림대학교 생명과학과는 세포와 분자, 그리고 생명 시스템의 원리를 깊이 있게 탐구합니다.”

#### 사운드
- 장면 전환 시 부드러운 whoosh
- BGM은 계속 유지

전공과 배움

## 6. 하단 스크립트 운영 원칙

- 화면 하단 고정 자막 영역 사용
- 장면 시작 시 해당 장면의 짧은 감성 내레이션으로 교체
- 문장은 짧고 영상 홍보 톤에 맞게 구성
- 발표 대본처럼 길지 않게 1~2문장으로 유지
- 자막 박스는 반투명 오버레이 적용 권장
- 읽기 속도를 고려해 장면당 1개의 짧은 내레이션 권장

## 7. 사운드 설계

### 7.1 배경음악
- 장르: 시네마틱 앰비언트 / 희망적인 홍보 영상 계열
- 분위기: 차분하게 시작해 중반부에 상승, 마지막에 감성적으로 마무리
- 음량: 시각 요소를 방해하지 않는 낮은~중간 정도

### 7.2 효과음
- 장면 전환: 부드러운 whoosh 계열
- 정보 패널 등장: 가벼운 UI 클릭/글로우 효과음
- 네트워크 연결: 짧은 상승감의 subtle chime
- 전체적으로 효과음은 절제된 수준 유지

### 7.3 구현 메모
- 브라우저 자동재생 제한 고려
- 사용자가 ‘시작’ 버튼을 눌렀을 때 BGM 재생 시작
- 음소거 버튼은 선택 기능으로 추가 권장

## 8. 버튼 및 인터랙션 설계

### 8.1 장면 선택 버튼
예시 버튼명:
- Scene 1 생명의 시작
- Scene 2 세포와 구조
- Scene 3 전공과 배움
- Scene 4 연구와 실험
- Scene 5 미래와 진로
- Scene 6 브랜딩 마무리

#### 동작
- 클릭 시 해당 장면 시작 시점으로 이동
- 이동 후 자동 재생하지 않고 **일시정지 상태 유지**
- 이후 사용자가 시작 버튼을 눌러 재생

### 8.2 재생 제어 버튼
- **시작 / 재생**: 현재 시점부터 재생
- **일시정지**: 현재 위치에서 정지
- **종료**: 0초 지점으로 복귀 후 정지
- **선택 기능**: 음소거/음량 조절

### 8.3 재생 종료 동작
- 30초가 지나면 자동 정지
- 마지막 장면(브랜딩 마무리) 화면을 유지한 채 멈춤

### 8.4 보조 UI
- 진행 바(progress bar)
- 현재 장면 하이라이트
- 시간 표시 예: `12s / 30s`

## 9. 단일 HTML 구현 사양

### 9.1 구조
단일 HTML 파일 안에 다음 요소를 포함한다.
- **HTML**: 장면, 버튼, 자막 영역, 진행 바
- **CSS**: 컬러 시스템, 애니메이션, 반응형 레이아웃
- **JavaScript**: 30초 타임라인 제어, 장면 이동, 오디오 제어, 자막 전환

### 9.2 권장 레이아웃
- 화면 비율: **16:9**
- 기준 크기: 1920 × 1080
- 반응형 축소 허용
- 구조:
  - 상단 또는 좌측: 장면 선택 버튼
  - 중앙: 메인 시각 영역
  - 하단: 스크립트/자막 + 제어 버튼

### 9.3 구현 방식 권장
- CSS 애니메이션 + JS 타임라인 제어 병행
- SVG 사용으로 벡터 기반 시각 요소 구성
- 각 장면 정보를 scene array 형태로 관리

예시 scene data 항목:
- `id`
- `name`
- `startTime`
- `endTime`
- `headline`
- `subline`
- `caption`
- `animationType`
- `soundCue`

### 9.4 오브젝트 구현 가이드
- **DNA**: SVG path + transform rotate
- **세포**: layered circles / organic blobs + opacity pulses
- **패널 카드**: div + CSS translate/opacity
- **실험실 도구**: simple SVG icon set
- **네트워크 진로 인포그래픽**: SVG nodes + line drawing animation
- **입자 효과**: canvas 또는 CSS dots animation

### 9.5 가독성/사용성 원칙
- 프로젝터 환경에서 잘 보이는 큰 텍스트 사용
- 과한 번쩍임보다 부드럽고 고급스러운 움직임 유지
- 학교 홍보 영상이므로 너무 복잡한 과학 그래픽보다 이해 가능한 수준으로 단순화
