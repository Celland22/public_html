# P4 로켓프레시 Motion Effect 최종 제작계획

## 1. 프로젝트 개요

- **대상 문제**: 문제 4. 신선식품(로켓프레시) 수요 예측과 폐기·품절 동시 감소
- **활용 맥락**: 대학생 대상 강의 중 문제 상황 설명용 Motion Effect 자료
- **최종 산출물 형식**: 단일 HTML 파일
- **총 재생 시간**: 30초
- **연출 콘셉트**: 타이포그래피 중심의 미니멀하고 세련된 프레젠테이션형 Motion Effect
- **핵심 교육 목적**: 문제 상황의 딜레마를 강렬하게 보여주기
- **브랜드 표현 원칙**: “로켓프레시” 명칭은 사용하되, 특정 기업 홍보처럼 보이지 않도록 중립적인 컬러와 설명 중심 톤 유지

---

## 2. 사용자 응답 반영 사항 요약

### 1차 답변 반영
- **교육 목적**: 문제 상황의 딜레마를 강렬하게 보여주기
- **타이포그래피 스타일**: 미니멀하고 세련된 프레젠테이션형
- **하단 설명 스크립트**: 교수자가 읽는 완성된 강의 멘트 형식
- **장면 선택 버튼 동작**: 해당 장면으로 이동 후 일시정지

### 2차 답변 반영
- **브랜드 표현**: 로켓프레시 명칭 사용 + 중립적 컬러 적용
- **배경/컬러**: 다크 네이비 배경 + 화이트 타이포
- **음향 효과**: 잔잔한 배경음악 + 장면 전환 효과음
- **재생 종료 방식**: 30초 종료 시 마지막 장면에서 정지
- **마지막 메시지**: “폐기와 품절, 동시에 줄일 수 있을까?”
- **해결 방법 노출 수준**: 마지막 5초에 “수요 예측”과 “Newsvendor” 키워드 소개

---

## 3. 전체 연출 방향

이 Motion Effect는 단순히 이론을 설명하는 영상이 아니라, 학생이 문제의 핵심 긴장감을 즉시 이해하게 만드는 짧은 인트로형 학습 자료로 설계한다.

핵심 연출 구조는 다음과 같다.

1. **문제 배경 제시**: 신선식품은 유통기한이 짧다.
2. **딜레마 제시**: 많이 주문하면 폐기, 적게 주문하면 품절.
3. **현행 방식의 한계 제시**: 단순 12% 가산 발주 규칙의 한계.
4. **핵심 질문 제시**: 어떻게 두 손실을 동시에 줄일 것인가?
5. **해결의 실마리 제시**: 수요 예측 + Newsvendor.
6. **토론 유도 마무리**: 학생에게 문제 해결 사고를 열어주는 질문으로 종료.

---

## 4. 화면 스타일 가이드

### 4.1 비주얼 스타일
- **배경색**: 다크 네이비 계열
- **기본 텍스트 색상**: 화이트
- **강조 텍스트**: 화이트 기반, 필요 시 저채도 포인트 색을 최소한으로 사용
- **톤 앤 무드**: 깔끔함, 절제된 긴장감, 학술 발표용
- **구성 방식**: 큰 키워드 중심, 짧은 문장, 여백 중심 레이아웃

### 4.2 타이포그래피 원칙
- 한 장면당 핵심 메시지 1개를 우선 노출
- 짧은 문장을 강한 리듬으로 분절 표시
- 단어 단위 강조 애니메이션 적극 활용
- 숫자, 비율, 대조 구조(많이/적게, 폐기/품절)를 시각적으로 대비

### 4.3 추천 타이포 효과
- **Fade In / Fade Out**: 기본 등장/퇴장
- **Slide Up / Slide Down**: 문장 전환 시 사용
- **Scale Up**: 핵심 키워드 강조
- **Word Stagger**: 단어별 순차 등장
- **Split Reveal**: 딜레마 구조 표현 시 좌/우 분할 노출
- **Pulse Emphasis**: “폐기”, “품절”, “딜레마”, “수요 예측”, “Newsvendor” 강조

---

## 5. 0~30초 장면별 상세 설계

총 6개 장면으로 구성한다.

---

### 장면 1 (0초 ~ 5초)
#### 장면명
문제 도입: 신선식품의 시간 압박

#### 화면 목표
신선식품은 일반 상품과 다르게 시간이 매우 중요한 품목임을 즉시 인식시킨다.

#### 메인 화면 문구
- 1행: **로켓프레시**
- 2행: **신선식품은 시간이 짧다**
- 보조 문구: **유통기한 2~10일**

#### 타이포그래피 효과
- “로켓프레시”는 부드러운 Fade In
- “신선식품은 시간이 짧다”는 단어별 Stagger 등장
- “유통기한 2~10일”은 숫자 강조 Scale Up 후 정착

#### 화면 구성 메모
- 중앙 정렬
- 여백을 넓게 두고 첫 장면은 차분하게 시작
- 숫자 “2~10일”은 상대적으로 크게 표현

#### 하단 교수자 강의 스크립트
“먼저 이 문제의 출발점은 신선식품입니다. 신선식품은 유통기한이 짧기 때문에, 일반 재고 문제보다 훨씬 민감하게 발주를 결정해야 합니다.”

---

### 장면 2 (5초 ~ 10초)
#### 장면명
핵심 딜레마 제시

#### 화면 목표
많이 주문하면 폐기, 적게 주문하면 품절이라는 핵심 충돌 구조를 강하게 인식시킨다.

#### 메인 화면 문구
- 좌측: **많이 주문하면**
- 좌측 강조: **폐기 증가**
- 우측: **적게 주문하면**
- 우측 강조: **품절 발생**
- 중앙 하단 보조 문구: **발주량은 항상 딜레마다**

#### 타이포그래피 효과
- 화면을 좌우로 분할
- 좌측 문구와 우측 문구가 각각 반대 방향에서 Slide In
- “폐기 증가”, “품절 발생”은 Pulse Emphasis
- 마지막에 “딜레마다”가 중앙에서 확대 등장

#### 화면 구성 메모
- 좌우 대칭 구도
- 두 위험을 동시에 보여주는 대비 구조가 핵심
- 시선이 자연스럽게 중앙 결론으로 모이게 설계

#### 하단 교수자 강의 스크립트
“여기서 가장 중요한 딜레마가 등장합니다. 많이 주문하면 남아서 폐기되고, 적게 주문하면 팔 수 없어서 품절이 발생합니다. 즉, 발주량은 늘 양쪽 손실 사이에서 결정됩니다.”

---

### 장면 3 (10초 ~ 15초)
#### 장면명
현재 방식의 한계

#### 화면 목표
현재 발주 규칙이 단순하며 상황 변화에 충분히 대응하지 못한다는 점을 보여준다.

#### 메인 화면 문구
- 1행: **현재 방식**
- 2행: **기존 시스템 예측값 + 12%**
- 3행: **하지만, 이 규칙은 단순하다**

#### 타이포그래피 효과
- “현재 방식” Fade In
- “기존 시스템 예측값 + 12%”는 수식처럼 타이핑 애니메이션
- “하지만, 이 규칙은 단순하다”는 아래에서 천천히 Slide Up
- “단순하다”는 살짝 확대 후 정지

#### 화면 구성 메모
- 중앙 정렬
- 수식형 표현으로 규칙의 단순함을 직관적으로 전달

#### 하단 교수자 강의 스크립트
“문제는 현재 발주 방식이 기존 시스템 예측값에 12퍼센트를 더하는 단순 규칙이라는 점입니다. 평소에는 그럭저럭 작동할 수 있어도, 수요가 크게 바뀌는 상황에는 약할 수 있습니다.”

---

### 장면 4 (15초 ~ 20초)
#### 장면명
이벤트 상황에서의 실패

#### 화면 목표
프로모션과 명절 같은 특수 상황에서 현재 방식이 왜 문제인지 드러낸다.

#### 메인 화면 문구
- 1행: **평소에는 폐기**
- 2행: **이벤트 기간에는 품절**
- 보조 문구: **프로모션 · 명절 수요 급증 반영 부족**

#### 타이포그래피 효과
- “평소에는 폐기”는 왼쪽에서 슬며시 등장
- “이벤트 기간에는 품절”은 오른쪽에서 빠르게 등장
- 보조 문구는 작은 크기로 Fade In
- “폐기”와 “품절”은 교차적으로 깜빡이지 않고 묵직하게 Pulse

#### 화면 구성 메모
- 상단/중앙/하단 3단 구성 가능
- 리듬감은 있으되 과하지 않게 유지

#### 하단 교수자 강의 스크립트
“특히 이 단순 규칙은 상황별로 다른 실패를 만듭니다. 평소에는 남는 재고가 늘어 폐기가 생기고, 프로모션이나 명절처럼 수요가 급증할 때는 오히려 품절이 발생합니다.”

---

### 장면 5 (20초 ~ 25초)
#### 장면명
핵심 질문 제시

#### 화면 목표
학생이 문제 해결 관점으로 전환되도록 핵심 질문을 던진다.

#### 메인 화면 문구
- 1행: **그렇다면**
- 2행: **어떻게 발주해야 할까?**
- 3행: **폐기와 품절을 함께 줄이려면?**

#### 타이포그래피 효과
- “그렇다면” 짧게 Fade In
- “어떻게 발주해야 할까?”는 크게 Scale Up
- “폐기와 품절을 함께 줄이려면?”은 아래에서 천천히 올라오며 정착
- 질문 장면이므로 움직임을 줄이고 정지감을 준다

#### 화면 구성 메모
- 화면 중앙 집중형
- 질문형 분위기 강조
- 학생이 다음 장면을 기대하도록 여백 사용

#### 하단 교수자 강의 스크립트
“이제 분석의 핵심 질문이 나옵니다. 우리는 어떻게 발주량을 정해야 폐기와 품절을 동시에 줄일 수 있을까요? 바로 여기서 데이터 분석과 모델링이 필요해집니다.”

---

### 장면 6 (25초 ~ 30초)
#### 장면명
해결 실마리 + 마무리 질문

#### 화면 목표
정답을 모두 말하지는 않되, 해결 방향인 수요 예측과 Newsvendor를 소개하고 토론형 질문으로 마무리한다.

#### 메인 화면 문구
- 상단: **해결의 실마리**
- 중앙 키워드 1: **수요 예측**
- 중앙 키워드 2: **Newsvendor**
- 마지막 메시지: **폐기와 품절, 동시에 줄일 수 있을까?**

#### 타이포그래피 효과
- “해결의 실마리”는 작게 Fade In
- “수요 예측”과 “Newsvendor”는 순차적으로 Slide Up + Scale Emphasis
- 마지막 문장 “폐기와 품절, 동시에 줄일 수 있을까?”는 화면 중앙에 크게 등장
- 30초 종료 시 마지막 화면 그대로 정지

#### 화면 구성 메모
- 처음엔 상단-중앙-하단 구조
- 마지막 2초는 질문 문구를 중심으로 구성
- 종료 후 정지 상태가 자연스러워야 함

#### 하단 교수자 강의 스크립트
“이 문제의 해결 방향은 마지막 5초에 제시됩니다. 첫째는 수요를 더 정확하게 예측하는 것이고, 둘째는 Newsvendor 모형처럼 폐기 비용과 품절 비용을 함께 고려해 적정 발주량을 정하는 것입니다. 결국 질문은 이것입니다. 폐기와 품절, 동시에 줄일 수 있을까요?”

---

## 6. 하단 교수자 스크립트 운영 원칙

- 화면 하단 고정 자막 영역에 장면별 멘트를 표시
- 자막은 각 장면 시작 시 교체
- 교수자가 그대로 읽을 수 있는 완성형 문장 제공
- 강의용이므로 지나치게 긴 문장은 피하고, 1장면당 1~2문장 수준 유지
- 텍스트 줄 수는 2~3줄 이내 권장
- 가독성을 위해 자막 영역은 반투명 오버레이 사용 가능

---

## 7. 버튼 및 인터랙션 기능 설계

HTML에는 다음 UI를 포함한다.

### 7.1 상단 또는 측면 장면 선택 버튼
- 버튼명 예시:
  - Scene 1 문제 도입
  - Scene 2 딜레마
  - Scene 3 현재 방식
  - Scene 4 이벤트 실패
  - Scene 5 핵심 질문
  - Scene 6 해결 실마리

#### 동작 방식
- 해당 버튼 클릭 시 그 장면 시작 시점으로 이동
- 이동 직후 자동 재생하지 않고 **일시정지 상태 유지**
- 사용자는 그 상태에서 시작 버튼을 눌러 재개 가능

### 7.2 재생 제어 버튼
- **시작 / 재생 버튼**: 현재 시점부터 재생
- **일시정지 버튼**: 현재 장면/시점에서 일시정지
- **종료 버튼**: 전체 애니메이션을 0초 상태로 되돌리고 정지

### 7.3 재생 종료 동작
- 30초가 지나면 자동으로 멈춤
- 마지막 장면을 유지한 채 정지
- 즉, 화면은 장면 6의 마지막 문구 상태로 남아 있어야 함

### 7.4 선택 기능 보조 요소
- 현재 장면 하이라이트 표시
- 진행 바(progress bar) 또는 타임라인 바 표시 권장
- 현재 시간(예: 12s / 30s) 표시 가능

## 8. 오디오 설계

### 8.1 배경음악
- 잔잔한 배경음악 사용
- 발표 흐름을 방해하지 않는 미니멀한 앰비언트 계열 권장
- 볼륨은 낮게 유지
- 교수자 음성이 들어갈 가능성을 고려해 음량 자동 조절 가능하게 설계하면 더 좋음

### 8.2 효과음
- 장면 전환 시 가벼운 전환 효과음 사용
- 텍스트 강조 시 과한 클릭음이나 타격음은 지양
- 프레젠테이션 느낌을 해치지 않는 얇고 절제된 효과음 권장

### 8.3 음향 관련 구현 고려
- 브라우저 자동재생 제한을 고려해 최초 사용자 클릭 후 오디오 시작
- 음소거 버튼 추가는 선택 사항이지만 있으면 유용

## 9. 구현 사양(HTML 제작 기준)

### 9.1 기술 구조
- 단일 HTML 파일로 구성
- 내부 포함 요소:
  - HTML: 화면 구조 및 버튼 UI
  - CSS: 레이아웃, 컬러, 타이포, 애니메이션 스타일
  - JavaScript: 장면 전환, 타이머, 재생 제어, 장면 선택 기능

### 9.2 권장 해상도 및 비율
- **16:9 비율** 권장
- 예시 해상도: 1920×1080 기준 레이아웃
- 반응형으로 축소 시에도 구조 유지

### 9.3 폰트 방향
- Sans-serif 계열
- 발표용 고가독성 폰트 권장
- 한글과 영문 키워드 모두 선명하게 보이도록 구성

### 9.4 애니메이션 구조 방식
- 방법 1: 타임라인 기반 클래스 토글
- 방법 2: JavaScript setTimeout / requestAnimationFrame 기반 장면 제어
- 장면 객체 배열(scene array)을 두고 다음 정보를 관리 권장:
  - 시작 시간
  - 종료 시간
  - 화면 문구
  - 자막 스크립트
  - 활성 버튼

### 9.5 접근성 및 사용성
- 텍스트 대비 충분히 확보
- 버튼 크기 너무 작지 않게 설계
- 강의실 프로젝터 환경에서 읽기 쉬운 큰 글자 사용
- 애니메이션 속도는 현란함보다 전달력 우선

## 10. 장면별 시간 요약표

| 시간 | 장면 | 핵심 내용 | 핵심 문구 |
|---|---|---|---|
| 0~5초 | 장면 1 | 신선식품의 시간 민감성 | 유통기한 2~10일 |
| 5~10초 | 장면 2 | 과잉/과소 발주의 딜레마 | 많이 주문하면 폐기, 적게 주문하면 품절 |
| 10~15초 | 장면 3 | 기존 발주 규칙의 단순함 | 기존 시스템 예측값 + 12% |
| 15~20초 | 장면 4 | 상황 변화 대응 실패 | 평소에는 폐기, 이벤트 때는 품절 |
| 20~25초 | 장면 5 | 핵심 질문 제시 | 어떻게 발주해야 할까? |
| 25~30초 | 장면 6 | 해결 실마리 + 마무리 질문 | 수요 예측, Newsvendor / 폐기와 품절, 동시에 줄일 수 있을까? |

## 11. 최종 제작 시 체크리스트

### 콘텐츠 체크
- [ ] 문제 4의 상황 배경이 정확히 반영되었는가
- [ ] 딜레마 구조가 직관적으로 드러나는가
- [ ] 마지막 5초에 수요 예측과 Newsvendor가 등장하는가
- [ ] 마지막 메시지가 “폐기와 품절, 동시에 줄일 수 있을까?”로 종료되는가

### UI 체크
- [ ] 장면 선택 버튼이 정상 작동하는가
- [ ] 장면 선택 후 자동으로 일시정지되는가
- [ ] 시작/일시정지/종료 버튼이 모두 동작하는가
- [ ] 종료 버튼 클릭 시 0초 상태로 돌아가 정지하는가
- [ ] 30초 종료 시 마지막 장면에서 자동 정지하는가

### 표현 체크
- [ ] 다크 네이비 배경 + 화이트 타이포가 일관되게 유지되는가
- [ ] 교수자 하단 멘트가 장면별로 교체되는가
- [ ] 강의실 프로젝터에서도 가독성이 확보되는가
- [ ] 애니메이션이 과하지 않고 발표용으로 적절한가
