# P4 로켓프레시 — 30초 Motion Effect 제작계획 (시각 효과 중심 수정판)

> 용도: 대학생 대상 AI 스마트워크 PBL 강의의 문제 도입 영상형 HTML
> 상태: 1·2차 Grill-me 답변 및 후속 피드백 반영 완료

## 1. 제작 목표

문제집의 **문제 4: 신선식품(로켓프레시) 수요 예측과 폐기·품절 동시 감소**를 30초 안에 직관적으로 소개한다. 긴 텍스트를 읽게 하지 않고, **움직이는 신선식품, 재고, 폐기통, 빈 선반, 수요 그래프**를 통해 학생이 발주 딜레마를 *보게* 한다.

- **핵심 질문:** SKU별 수요를 더 정확히 예측하고 유통기한과 비용 구조를 고려한 최적 발주량을 정할 수 있는가?
- **학습 도입 메시지:** 많이 발주하면 폐기, 적게 발주하면 품절. 단순한 일괄 가산 발주는 상황 변화에 대응하기 어렵다.
- **해결 실마리 노출 범위:** 마지막 5초에만 `수요 예측` 및 `Newsvendor` 언급. 정답이나 공식은 설명하지 않는다.
- **사례의 성격:** 쿠팡을 모티브로 한 **가상 교육 사례**. 결과 숫자를 실제 쿠팡의 실적으로 제시하지 않는다.

## 2. 확정된 연출 조건

| 화면 비율 | 강의용 16:9, 반응형 |

### 비주얼 비중 목표

- 상황 애니메이션: **40%** — 식품과 박스, 선반, 폐기통, 주문 흐름
- 모션 인포그래픽: **40%** — 재고 게이지, 주문 수요, 예측선, 손실 비교
- 키네틱 타이포그래피: **20%** — 장면 제목 및 핵심 한두 단어만 강조

※ 위 수치는 디자인 방향을 위한 권장 비중이며 분석 결과가 아니다.

## 4. 장면별 정밀 스토리보드와 교수자 스크립트

### SCENE 01 · 00:00–00:05 · 신선식품의 시간 압박

**핵심 메시지:** 신선식품은 시간이 지날수록 판매 가능한 기간이 줄어든다.

**시각 구성:** 중앙의 깨끗한 상품 선반 위에 채소·과일·정육·수산 아이콘(벡터 SVG)이 각각 들어온다. 오른쪽에는 `2~10일` 표시가 있는 원형 시간 게이지. 브랜드 명칭은 작은 상단 레이블.

**초 단위 모션**
- 0.0–1.0초: 선반과 `로켓프레시` 레이블 부드럽게 등장
- 1.0–2.3초: 각 식품 아이콘이 좌우에서 미끄러지며 선반에 착지
- 2.3–4.0초: 타이머 링이 진행되며 `유통기한 2~10일` 표시
- 4.0–5.0초: 약한 색 변화로 ‘시간 제약’ 암시, 다음 장면으로 전환

**중앙 화면 텍스트:** `신선식품` · `유통기한 2~10일`

**하단 교수자 스크립트:**
> 신선식품은 보관할 수 있는 기간이 짧습니다. 그래서 필요한 양을 제때 발주하지 못하면 일반 상품보다 손실이 쉽게 발생합니다.

**연출 유의:** 원문 상황 설명의 유통기한 `2~10일`을 화면에 사용. 원문의 데이터 변수 범위 `2~11일`과 혼동하지 않도록 ‘사례 상황’으로 표시.

### SCENE 02 · 00:05–00:10 · 과잉 발주와 폐기

**핵심 메시지:** 많이 주문하면 팔리지 않은 물량이 남아 폐기된다.

**시각 구성:** 식품 박스가 선반 용량을 넘게 쌓인다. 일부 식품의 채도가 낮아지고, 남은 박스가 폐기통 아이콘으로 이동한다. 재고량 막대는 상승하고 폐기 수량 점 아이콘이 증가한다.

**초 단위 모션**
- 5.0–6.2초: 박스 2~3개 들어오고 선반에 쌓임
- 6.2–7.6초: 박스가 더 쌓이면서 공간이 부족해짐
- 7.6–9.0초: 재고 일부가 회색으로 바뀌고 폐기통으로 이동
- 9.0–10.0초: `폐기 증가` 짧게 강조, 오른쪽 하단에 폐기 비용 아이콘

**중앙 화면 텍스트:** `과잉 발주` → `폐기 증가`

**하단 교수자 스크립트:**
> 수요보다 많이 발주하면 재고가 남습니다. 신선식품은 오래 보관하기 어려워서 남은 물량이 폐기로 이어지고, 결국 원가 손실이 발생합니다.

### SCENE 03 · 00:10–00:15 · 과소 발주와 품절

**핵심 메시지:** 적게 주문하면 판매 기회를 놓친다.

**시각 구성:** 장면 2와 비슷한 선반을 재사용하되 이번에는 상품 수량이 적다. 고객 주문을 뜻하는 작은 주문 카드들이 빠르게 나타나고, 재고 게이지가 `100 → 0` 같은 *비율 예시*로 줄어든다. 마지막에 선반이 비어 있고 주문 카드 일부는 처리되지 않은 상태로 남는다.

**초 단위 모션**
- 10.0–11.4초: 상품이 적게 놓인 선반과 주문 카드 유입
- 11.4–12.7초: 주문에 따라 식품이 하나씩 선반에서 사라짐
- 12.7–14.0초: 재고 게이지가 0에 도달, 빈 선반 표시
- 14.0–15.0초: 미처리 주문 카드가 남고 `품절 발생` 강조

**중앙 화면 텍스트:** `과소 발주` → `품절 발생`

**하단 교수자 스크립트:**
> 반대로 적게 발주하면 재고가 먼저 떨어집니다. 고객이 구매하려 해도 판매할 수 없기 때문에 매출뿐 아니라 이익을 얻을 기회까지 놓치게 됩니다.

**연출 유의:** 게이지 수치는 개념 설명용 애니메이션이지 실제 데이터 분석 결과가 아님.

### SCENE 04 · 00:15–00:20 · 현재 방식의 한계

**핵심 메시지:** 기존 예측에 12%를 더하는 규칙은 이벤트 수요 변동을 충분히 반영하지 못한다.

**시각 구성:** 가로축 `평소 → 프로모션/명절`, 세로축 `수요량`인 간단한 개념 그래프. 흰색 실선은 기존 시스템 예측, 청회색 점선은 12% 가산 발주 수준, 밝은 포인트 선은 실제 수요의 이벤트 구간 상승을 의미한다. 실제 수요선은 이벤트 시작점에서 발주 수준보다 높아진다.

**초 단위 모션**
- 15.0–16.0초: 그래프 축과 시스템 예측선 등장
- 16.0–17.0초: `+12%` 레이블이 뜨고 발주선 상향 표시
- 17.0–18.5초: 이벤트 구간 하이라이트와 실제 수요 급증 곡선 표시
- 18.5–20.0초: 실제 수요와 발주선 사이 간극을 음영으로 강조

**중앙 화면 텍스트:** `기존 예측 +12%` · `이벤트 수요 급증`

**하단 교수자 스크립트:**
> 현재 발주는 시스템의 수요 예측값에 12퍼센트를 더하는 방식입니다. 하지만 프로모션이나 명절에 수요가 급증하면, 이 단순한 규칙만으로는 필요한 물량을 맞추기 어렵습니다.

**연출 유의:** 그래프는 원리 설명용 **개념도**로 표현하고, 실제 예측 정확도나 실측 수치처럼 보이게 하지 않는다.

### SCENE 05 · 00:20–00:25 · 폐기와 품절, 두 비용

**핵심 메시지:** 발주 의사결정은 폐기 손실과 품절 기회손실의 균형 문제다.

**시각 구성:** 좌측 `폐기 손실 = 원가 × 폐기량`, 우측 `기회손실 = 마진 × 품절량`을 설명하는 2개의 미니 카드와 저울 형태의 비주얼. 발주량 슬라이더가 왼쪽·오른쪽으로 조금 움직이면 두 카드의 막대 높이가 반대로 변한다. 결과값은 *임의 금액*을 제시하지 않고 상대적 막대로만 표현.

**초 단위 모션**
- 20.0–21.0초: 폐기 비용 카드가 왼쪽에 등장
- 21.0–22.0초: 품절 기회손실 카드가 오른쪽에 등장
- 22.0–24.0초: 발주량 조절에 따라 좌우 손실 막대의 높이가 반대 방향으로 변함
- 24.0–25.0초: 두 카드가 중앙의 균형점 쪽으로 수렴

**중앙 화면 텍스트:** `폐기 손실` ↔ `품절 기회손실`

**하단 교수자 스크립트:**
> 발주량을 결정할 때는 폐기로 잃는 원가만 볼 수 없습니다. 재고가 부족해서 놓치는 판매 이익도 함께 고려해야 합니다. 두 손실을 함께 줄이는 것이 목표입니다.

### SCENE 06 · 00:25–00:30 · 해결의 실마리와 최종 질문

**핵심 메시지:** 수요 예측과 Newsvendor를 활용해 발주 의사결정을 개선할 수 있을지 탐색한다.

**시각 구성:** 이전 장면의 단순 예측선을 개선된 예측 곡선 이미지로 전환한다. 키워드 `수요 예측`과 `Newsvendor`가 작은 태그 형태로 나타난다. 이어서 상품 상자·재고 게이지·손실 저울이 정돈된 하나의 화면으로 조합된다. 마지막 1.5초에는 질문을 크게 배치하고 **그 상태로 정지**한다.

**초 단위 모션**
- 25.0–26.2초: 예측 그래프가 정돈되며 `수요 예측` 태그 등장
- 26.2–27.4초: 저울의 두 비용이 균형을 향해 이동하며 `Newsvendor` 태그 등장
- 27.4–28.5초: 시각 요소 크기를 줄여 배경으로 배치, 최종 질문 등장
- 28.5–30.0초: `폐기와 품절, 동시에 줄일 수 있을까?` 안정적으로 유지
- **30.0초:** 애니메이션 정지, 마지막 질문 화면과 마지막 스크립트 유지

**중앙 화면 텍스트:** `수요 예측` · `Newsvendor` → **`폐기와 품절, 동시에 줄일 수 있을까?`**

**하단 교수자 스크립트:**
> 그렇다면 어떻게 해결할 수 있을까요? 수요를 더 정확하게 예측하고, Newsvendor 모형으로 폐기 비용과 품절로 인한 기회손실을 함께 고려해 발주량을 정하는 것이 한 가지 방향입니다. 과연 두 문제를 동시에 줄일 수 있을까요?

**연출 유의:** 실제 분석 없이 ‘최적화 완료’, ‘폐기율 30% 감소’ 같은 확정 결과는 표시하지 않는다.

- 중앙 애니메이션은 화면의 가장 큰 영역을 사용.
- 하단 스크립트는 독립적인 패널에 표시하고 교수자가 읽기 쉽게 줄바꿈 처리.
- 장면 제목·자막과 실제 그림의 중요도: **그림 > 키워드 > 상세 스크립트**.

## 6. HTML 구현 사양

### 6.1 단일 파일 및 오프라인 동작
- 하나의 `.html`에 HTML/CSS/JS 및 주요 SVG 일러스트를 **인라인 포함**한다.
- 외부 CDN, 외부 이미지 링크, 인터넷 연결에 의존하지 않는다.
- 아이콘은 SVG로 직접 제작하여 동일한 디자인 언어 유지.
- 글꼴은 시스템 한글 sans-serif 폴백 사용.

### 6.2 애니메이션 엔진
- `requestAnimationFrame`과 단일 **논리적 재생 시각(currentTime)** 을 사용해 화면 상태를 계산한다.
- 애니메이션 상태는 시스템 시간 대신 `currentTime`에 종속되도록 설계한다. 따라서 장면 이동·일시정지·재개 후에도 시각 요소와 진행 바가 일치한다.
- 장면 범위: `[0,5), [5,10), [10,15), [15,20), [20,25), [25,30]`.
- 각 SVG 도형 위치, 투명도, 크기, 그래프 선 그리기 효과는 로컬 시간에 따라 변경.
- 장면 버튼 클릭 시 `currentTime = 해당 장면 시작초`, `isPlaying = false`.
- 30초 도달 시 `currentTime = 30`, `isPlaying = false`, 마지막 장면 최종 상태 표시.
- 종료 버튼 클릭 시 `currentTime = 0`, `isPlaying = false`.

### 6.3 버튼과 피드백
- **장면 1~6:** 선택한 장면으로 이동 후 즉시 일시정지. 버튼 활성 상태 표시.
- **시작:** 0~29.999초 구간에서는 재개, 30초에서는 0초부터 다시 시작.
- **일시정지:** 현재 프레임을 고정.
- **종료:** 0초 첫 화면으로 이동 후 정지.
- **음소거:** 클릭 시 BGM과 전환 효과음 모두 비활성화.
- **진행 표시:** 00:00~00:30 현재 시각과 시각적 진행 바.
- **키보드 접근성(권장):** Space 재생/일시정지, 숫자 1~6 장면 이동, Esc 종료.

### 6.4 음향 설계
- 외부 음악 파일 없이도 단일 HTML에서 작동하게 하려면, **Web Audio API를 통한 미니멀 앰비언트 사운드**(서로 다른 낮은 주파수의 부드러운 음색)와 짧은 전환 효과음을 자체 합성한다.
- 일반 음원 파일이 반드시 필요한 경우에는 사용 허가된 소스를 별도 확보해야 한다. *본 계획에서는 오프라인 단일 파일 작동을 우선해 합성형 배경음을 기본안으로 채택한다.*
- 사용자가 **재생 버튼을 누른 뒤** 오디오 컨텍스트 시작(브라우저 자동재생 제한 대응).
- 일시정지 시 오디오도 멈추고, 장면 선택 후 정지 상태에서는 소리 재생 없음.
- 초기 음량은 낮게 설정하며 음소거 가능.

## 9. HTML 구현을 위한 최종 지시문

> 다크 네이비 배경과 화이트 타이포를 유지한 30초짜리 단일 HTML 강의용 Motion Effect를 제작한다. 타이포그래피는 최소화하고, SVG 신선식품·상품 박스·선반·폐기통·주문 카드·재고 게이지·수요 그래프·비용 비교 저울을 시간에 맞춰 애니메이션한다. 6개 장면은 5초씩 구성하며, 각 장면의 교수자 설명 스크립트를 하단 고정 패널에 노출한다. 사용자는 장면 버튼으로 이동 후 정지, 시작, 일시정지, 종료, 음소거를 조작할 수 있다. 총 30초 종료 시 마지막 질문을 화면에 유지한다. 마지막 5초에는 `수요 예측`, `Newsvendor`만 해결 실마리로 제시하고, `폐기와 품절, 동시에 줄일 수 있을까?`를 마지막 문구로 고정한다. 외부 리소스에 의존하지 않도록 구현한다.
