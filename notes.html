LAB NOTE #01 · 원본: 발표자료 생성.docx
1. 실습 목적 & 도구

• 목적: 이미지 캡처 대신 수정 가능한 native 도형과 텍스트 박스로 구성된 고품질 파워포인트 슬라이드를 원클릭으로 자동 생성하는 커스텀 스킬 파이프라인 구축.

• 도구/자료: Claude 3.5 Sonnet, hallym-edu-pptx (커스텀 스킬 ZIP), MS Office Open XML 스펙.

2. 실제 작업 과정 & 핵심 프롬프트

• SKILL.md에 디자인 원칙(16:9 와이드, 4열 카드 그리드, 제목-본문 계층 구조)을 주입하고 XML 구조 템플릿을 ZIP으로 패키징.

• "본문의 도식화는 절대로 AI가 그린 래스터 이미지를 넣지 말고, 파워포인트 내장 Shape 및 편집 가능한 SVG 벡터로만 조립할 것" 제약 부여.

3. 실제 결과물 & 디버깅 과정

• 결과: 폐_미생물군집의_유지와_질환.pptx 및 중간고사 발표 슬라이드 XML 완벽 렌더링 성공.

• 문제 해결: 초기 XML 생성 시 한글 인코딩 깨짐 및 슬라이드 번호 중복 에러 발생 $\rightarrow$ XML Declaration UTF-8 고정 및 관계 정의 파일(.rels) 자동 번호 부여 스크립트로 해결.

4. 배운 점 & 원본 다운로드

• 인사이트: 생명과학 논문 세미나 시 서식 편집에 쏟던 시간을 줄이고 학술 연구 내용 검증에 집중할 수 있음.
