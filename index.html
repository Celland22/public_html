PART 1 & 2

프롬프트 엔지니어링 및 보고서 자동화

환각 방지 프롬프트 설계 · Claude 커스텀 스킬 hallym-edu-pptx 파이프라인

1. 환각 방지(Anti-Hallucination) 프롬프트 설계

산업·기업 심층 보고서 작성 시 DART 공시 및 공식 IR 기준일 통일, 확정/잠정 실적 및 연결/사업부 수치 구분, 근거 없는 추정 차단 규칙을 구조화하여 보고서의 사실 검증력을 확보했습니다.

2. hallym-edu-pptx 커스텀 스킬 구현

황현석 교수님 전용 템플릿(template.pptx)의 XML 구조를 직접 제어하는 Claude 커스텀 스킬을 제작하여, Navy/Gold 테마·SVG 도형·학과 푸터가 고정된 25페이지 발표 자료와 DOCX/HWPX 보고서 자동 생성 파이프라인을 구축했습니다.

1. Grill-me 역질문 기반 System Role 설계

단방향 지시·응답 방식에서 벗어나, PDF를 업로드하면 AI가 먼저 "몇 장으로 구성할까요?", "독자 타깃과 핵심 강조점은 무엇인가요?"라고 되물으며 요구사항을 구체화하는 맞춤형 인터뷰 봇을 구축했습니다.

2. 스토리보드 및 타이포그래피 카드뉴스 자동 생성

사용자 답변이 확정되면 PDF 핵심 문맥을 7장 분량의 스토리보드로 자동 구조화하고, 일관된 타이포그래피·컬러 톤이 적용된 카드뉴스 이미지 세트까지 원스톱으로 연동 출력하도록 자동화했습니다.

AI 스마트워크 기말 과제 종합 소감

한 학기 전만 해도 생성형 AI는 질문에 대한 답을 대신 찾아주는 편리한 검색형 챗봇에 가까웠습니다. 그러나 황현석 교수님의 'AI 스마트워크' 강의를 통해 AI를 수동적으로 소비하는 수준을 벗어나, 업무의 맥락에 맞게 도구를 설계하고 검증하며 끝까지 배포하는 능동적 빌더(Builder)로 관점이 완전히 전환되었습니다.

보고서와 발표 자료 자동화 과정에서는 환각을 차단하는 구조화 프롬프트와 hallym-edu-pptx 커스텀 스킬로 반복 문서 작업의 표준화를 구현했고, 데이터 분석 파트에서는 Python 환경의 패키지 오류를 AI와 함께 직접 디버깅하며 머신러닝 예측 모델과 재고 최적화 시뮬레이션, 엑셀 이중축 시각화까지 완수했습니다.

나아가 ABSOLUTE CONTINUITY LOCK 기반의 시간차 영상 렌더링 통제, Google GEMS와 Grill-me 기법을 활용한 역질문형 카드뉴스 봇 구축, 그리고 Git 버전 관리와 Netlify 자동 웹 배포에 이르기까지 현대 실무에 필수적인 에이전틱 워크플로우 전 과정을 온전히 내 기술 스택으로 체화할 수 있었습니다.

앞으로 경영학적 비즈니스 의사결정 역량과 생명과학 복수전공의 데이터 탐구 역량 위에 이번 학기 체득한 AI 오케스트레이션 기술을 결합하여, 현장의 복잡한 문제를 자동화된 솔루션으로 풀어내는 실무형 융합 인재로 나아가겠습니다.
