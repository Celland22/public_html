ABSOLUTE CONTINUITY LOCK 시간차 렌더링 통제 로직

생성형 이미지·영상 AI에서 발생하는 손가락 증식, 소품 위치 변경, 얼굴 형태 붕괴(Morphing)를 통제하기 위해 0초 → 3초 → 6초 → 10초 → 12초 → 14초 → 16초 → 18초 → 20초의 9단계 순차 생성 규칙과 불변 잠금 계층을 설계했습니다.

LOCK 01 · 왼손 & 어깨 불변

고정 소품 물리 위치 잠금

0~20초 전 구간에서 왼손은 동일한 스타벅스 커피컵 1개만 들고, 왼쪽 어깨에는 동일한 검정 토트백 1개만 착용하도록 강제했습니다.

LOCK 02 · 오른손 타임라인

동작 주체 분리 제어

오직 오른손만 시간대별 액션(0~3s 사원증 태그 → 6~10s 스윙 → 12s 버튼 접근 → 14s 클릭 → 16~20s 대기)을 수행하도록 역할을 분리했습니다.

LOCK 03 · 직전 프레임 승계

Primary Temporal Reference

매 단계마다 캐릭터 시트·컵 레퍼런스와 함께 바로 직전 정상 검증 프레임을 주 레퍼런스로 투입해 카메라 축과 인체 비율을 유지했습니다.
