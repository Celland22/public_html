프롬프트 엔지니어링 및 보고서·발표자료 자동화

환각(Hallucination)을 구조적으로 차단하는 분석 프롬프트 설계와, Claude 커스텀 스킬(hallym-edu-pptx / my_pptx_skill)을 통한 XML 기반 발표자료·DOCX·HWPX 자동 생성 파이프라인입니다.

Part 1 · Reliability Architecture

환각 방지(Anti-Hallucination) 프롬프트 설계 원칙

적용 사례: 2026 한국 메모리 반도체 보고서 · 글로벌 HR 보고서

생명과학 논문을 읽고 실험 데이터를 검증하듯, 비즈니스 및 산업 리서치 보고서에서도 생성형 AI의 임의 추정과 출처 혼동을 원천 차단하는 5가지 제약 규칙을 프롬프트 템플릿으로 고정했습니다.

RULE 01

기준일 및 출처 계층 고정

전자공시(DART), 공식 IR 실적 발표, KRX, WSTS 등 1차 공신력 자료를 최우선하고 모든 주가·실적 데이터에 공통 기준일(예: 2026-10-16)을 강제했습니다.

RULE 02

연결/사업부 · 확정/잠정 분리

삼성전자와 SK하이닉스 비교 시 사업부 구성 차이를 무시한 기계적 영업이익률 해석을 금지하고, 확정 실적과 잠정 실적을 명시적으로 구분했습니다.

RULE 03

1-Page 요약 → 5~10p 심층 구조

Executive Summary 1페이지 선행 후 상세 분석 본문과 본문 내 인용 번호([1])·참고문헌을 매칭해 문서 추론 투명성을 확보했습니다.

Part 2 · Claude Custom Skill Engineering

Claude 커스텀 스킬 hallym-edu-pptx 아키텍처

단순 HTML-to-PPTX 변환이 아니라, 실제 PowerPoint 템플릿(assets/template.pptx)의 XML을 직접 복제·편집해 배경 아트워크와 학술 브랜딩을 픽셀 단위로 보존하는 커스텀 스킬 파이프라인입니다.

슬라이드 템플릿 XML 매핑 및 고정 요소

슬라이드 유형 XML 소스 레이아웃 역할
1. Title slide1.xml 제목 슬라이드 · Navy/Gold 표지 및 고정 소속
2. Agenda / TOC slide2.xml 목차 및 발표 흐름 구조화
3. General Content slide3.xml 개조식 본문 + 편집 가능 pptx-native / SVG 도식
4. Section Break slide4.xml 대주제 전환 구분 슬라이드
5. Closing / Q&A slide5.xml 질의 응답 및 연락처 블록 고정
생명과학 주전공 확장 적용 (my_pptx_skill): 동일한 스킬 구조(SKILL.md + assets + references + scripts)를 생명과학 전공 발표용으로 커스텀화하여, 논문·PDF 자료인 「폐 미생물군집의 유지와 질환」 발표 자료를 개조식 + 편집 가능 도식 슬라이드로 자동 생성했습니다.
Build & Validation Pipeline
  1. STEP 1 · UNPACK

    assets/template.pptx 압축 해제 후 원본 아트워크 보존

  2. STEP 2 · CLONE SLIDES

    add_slide.py로 25p 분량에 맞춰 슬라이드 XML 사전 복제

  3. STEP 3 · REPLACE & SVG

    도형 구조를 훼손하지 않고 플레이스홀더 치환 및 편집 가능 SVG 도식 삽입

  4. STEP 4 · CLEAN & VALIDATE

    clean.py · validate.py로 XML 무결성 검증 후 패키징

실제 생성 결과물 및 스킬 파일 링크

Git 저장소와 Netlify에 함께 배포된 실제 산출물을 바로 확인하거나 다운로드할 수 있습니다.
